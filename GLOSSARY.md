# Domain glossary

## Compose Multiplatform (CMP)
A framework for sharing application user interfaces across platforms.

## Host application
The application that incorporates the chat library and owns its users, data, and services.

## Conversation
A sequence of messages exchanged by participants.

## Participant
A person or service represented as a sender in a conversation.

## Current participant
The participant on whose behalf the host application presents a conversation.

## Message
An identified contribution to a conversation, with a sender and content.

## Draft
Unsent content being composed for a conversation.

## Timeline
The ordered presentation of a conversation’s messages.

## History page
A portion of earlier messages supplied to extend the timeline.

## Attachment
Content associated with a message in addition to its text, such as an image.

## Quoted reply
A message that refers to an earlier message and presents a short excerpt or an unavailable-message fallback.

## Delivery state
The host application's report of a message's sending progress or outcome.

## Message action
An operation offered for a particular message, such as copying, replying, editing, or deleting.
